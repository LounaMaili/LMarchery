# Planches de contrôle R18

Chaque planche associe pixels sources et calques dans le même repère. Les détails de fûts sont redressés et agrandis transversalement. Le trait blanc suit l’axe admis, la couleur identifie le fût, le cercle orange situe l’entrée admise, le jaune une exclusion. Sur les deux détails Crigges, le trait bleu est le polygone source. Dans les deux loupes de correction, le cercle rouge est la valeur historique et le cyan la valeur R18. La [visionneuse hors ligne](../visionneuse.html) dissocie les calques et ouvre chaque vue sur les pixels seuls. Les [matrices de projection](index.json) relient les pixels originaux orientés au panneau par le repère R18. [Effectifs par tâche](bilan.svg) · [Données de la figure](../effectifs.json)
